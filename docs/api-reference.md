# API reference

The complete HTTP API, generated from the server's code and checked against it in CI:
every endpoint, request and response schema, and error.

- [Open the interactive reference](api/reference.html){ .md-button .md-button--primary }
- [Download the OpenAPI 3.1 document](api/openapi.json){ .md-button }

A running server also serves the document at `GET /api/v1/openapi.json`. For a guided
tour with examples, the SDK and the CLI, see [Using the API](api.md).
